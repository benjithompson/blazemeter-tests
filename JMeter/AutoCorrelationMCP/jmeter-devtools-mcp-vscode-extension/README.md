# jmeter-devtools-mcp-vscode-extension

## Overview
The JMeter DevTools MCP VS Code Extension provides an easy-to-use interface for integrating JMeter with Chrome DevTools. This extension aims to simplify performance testing and debugging for less technical end users by offering a push-button solution to start and manage JMeter tests while ensuring all necessary context is available.

## Features
- Start and stop JMeter tests directly from VS Code.
- Retrieve and display test results in a user-friendly interface.
- Manage configurations and preferences for JMeter tests.
- Seamless integration with Chrome DevTools MCP for enhanced context management.

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/jmeter-devtools-mcp-vscode-extension.git
   ```
2. Navigate to the project directory:
   ```
   cd jmeter-devtools-mcp-vscode-extension
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage
1. Open the command palette in VS Code (Ctrl+Shift+P).
2. Type and select the command to start a JMeter test.
3. Follow the prompts to configure your test settings.
4. View the results in the webview panel.
